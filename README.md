# 360-Panorama

Веб-приложение для интерактивных 360°-панорам объектов с возможностью размещения графических выносок/аннотаций и защищенной публикации по криптографическому токену и QR-коду.

---

## 1. Архитектура и стек

### Технологический стек:
- **Backend**: Laravel 13 (PHP 8.4), Laravel Sanctum (API token auth), Eloquent ORM, Pest тесты.
- **Frontend**: React 18, TypeScript, Vite, Tailwind CSS, Lucide React, React Router.
- **Просмотрщики панорам**:
  - **Фиксированная панорама (`flat`)**: нативный pan-and-zoom просмотрщик со 100% фиксацией высоты экрана, плавным горизонтальным перемещением (влево/вправо), зумом от 1.0x до 5.0x и поддержкой исходного разрешения без сферических искажений.
  - **360° Сфера (`360`)**: WebGL просмотрщик **Pannellum** для равнопромежуточных эквидистантных сферических снимков (2:1).
  - Переключение режимов поддерживается динамически для каждой комнаты как в карточке объекта, так и в редакторе аннотаций.
- **Интерактивные аннотации**:
  - **Архитектурная линейка/размер (`measurement`)**: реальная размерная линия с перпендикулярными засечками по нормали вектора, стрелками, бейджем размера и независимым перетаскиванием точек А и Б (а также всей размерной линии целиком). Размещение в 2 клика (Точка А -> резиновая нить превью -> Точка Б).
  - **Выноска (`callout`)**: интерактивная точка с линией-выноской и подробной карточкой описания.
  - **Текстовая плашка (`label`)**: аккуратная плашка с названием зоны.
  - **Маркер (`marker`)**: пульсирующий маячок с открываемой информацией.
- **Система координат аннотаций**:
  - Процентная система (`x`, `y`, `x2`, `y2` в диапазоне `0..100%`) для точного позиционирования на исходном изображении.
  - Сферическая система (`yaw` `-180..+180`, `pitch` `-90..+90`) для 360° режима.
- **Инфраструктура**: Docker Compose (`frontend`, `backend`, `webserver` Nginx, `mysql`, `phpmyadmin`).

## 2. Сетевая схема и порты

| Сервис | Порт хоста | Внутренний адрес | Описание |
|---|---|---|---|
| **Frontend** | `http://localhost:5173` | `frontend:5173` | React + Vite UI (Админка и просмотрщик) |
| **Backend API** | `http://localhost:8000` | `webserver:80` | Nginx прокси к PHP-FPM (`backend:9000`) |
| **phpMyAdmin** | `http://localhost:8081` | `phpmyadmin:80` | Веб-интерфейс БД для локальной разработки |
| **MySQL** | Внутренний | `mysql:3306` | MySQL 8.4 с healthcheck и named volume |

## 3. Быстрый старт

### 1. Запуск всех сервисов в Docker
```bash
docker compose up -d --build
```

### 2. Выполнение миграций и сидирование (создание учётной записи администратора)
```bash
docker compose exec backend php artisan migrate --seed
```

### 3. Вход в админку в браузере
Откройте: **`http://localhost:5173/admin/login`**
- **Email:** `admin@example.com`
- **Пароль:** `password`

После входа доступна панель управления (`/admin`), создание объектов, загрузка 360°-панорам, редактор выносок и публикация с генерацией QR-кода.

## 4. Маршруты приложения

### Frontend маршруты
- `/admin/login` — форма входа администратора.
- `/admin` — дашборд с количеством объектов и черновиков.
- `/admin/objects` — каталог объектов с поиском, фильтрами и действиями.
- `/admin/objects/:id` — карточка объекта, загрузка панорам, сортировка, публикация, модальное окно QR-кода.
- `/admin/objects/:id/panoramas/:panoramaId` — полноэкранный визуальный 360° редактор аннотаций (плашки, размеры, выноски, маркеры).
- `/view/:publicToken` — мобильная адаптивная страница просмотра объекта с переключением комнат и интерактивными элементами.

### Backend API
Полный список из 32 API-маршрутов описан в коде и протестирован:
- `/api/admin/login`, `/api/admin/logout`, `/api/admin/me`
- CRUD `/api/admin/objects`, `/api/admin/objects/{id}/publish`, `/api/admin/objects/{id}/regenerate-token`, `/api/admin/objects/{id}/qr`
- CRUD `/api/admin/objects/{id}/panoramas`, `/api/admin/panoramas/{id}`, сортировка
- CRUD `/api/admin/panoramas/{id}/annotations`, `/api/admin/annotations/{id}`, сортировка
- Публичный эндпоинт `/api/public/objects/{publicToken}` (с ограничением 60 запросов в минуту).
